# 金刚石/Cu 中间层的自动化设计

用 NEMD + 机器学习势，自动搜索金刚石/Cu 界面的**中间层**最优设计
（碳化物家族 × 厚度 × 终端 × 取向 × 梯度），给出可交付的设计地图。

## 0. 为什么做中间层，而不是继续做图案化

前一个项目（`Diamond-Ti-Cu-NEMD`）已经系统扫过界面图案化：12 个算例，
几何互锁与化学合金化**全部使热阻升高 1.9–2.5 倍**，平面即最优。

所以真正的自由度不在界面"形状"，而在**界面之间放什么**。

## 1. 能力矩阵：这个势能算什么、不算什么

势模型：`potentials/CuTiC_NEP.txt`（元素 **Cu C Cr Mo Ti W**，24k 参数，
来自 Cu/X/diamond 界面热输运的专用训练）。

体相标定（`tools/capability_matrix.py`，细网格 + 抛物线顶点）：

| 相 | 计算 a₀ (Å) | 实验 (Å) | 偏差 | 结论 |
|---|---|---|---|---|
| C 金刚石 | 3.590 | 3.567 | +0.7% | ✅ |
| Cu fcc | 3.666 | 3.615 | +1.4% | ✅ |
| Ti hcp | 2.944 | 2.951 | −0.2% | ✅ |
| Cr bcc | 2.865 | 2.884 | −0.7% | ✅ |
| Mo bcc | 3.186 | 3.147 | +1.2% | ✅ |
| W bcc | 3.205 | 3.165 | +1.3% | ✅ |
| **TiC rocksalt** | **4.357** | 4.328 | **+0.7%** | ✅ |
| **WC P-6m2** | **2.960** | 2.906 | **+1.9%** | ✅ |
| CrC rocksalt（代理相） | 3.870 | 4.130 | −6.3% | ⚠️ 相不对或势未覆盖 |
| MoC rocksalt（代理相） | 4.655 | 4.280 | +8.8% | ⚠️ 同上 |

**结论**：可在本势内研究的中间层材料 = **TiC、WC、Ti、Cr、Mo、W**，
以及它们的组合与梯度。CrC / MoC 暂不纳入（真实相是 Cr₃C₂、Mo₂C，需要先验证正确相）。

**不能算**：SiC（无 Si）、N 终端（无 N）。要纳入必须先换/微调势。

## 2. 设计空间

| 变量 | 取值 |
|---|---|
| 中间层材料 | TiC / WC / Ti / Cr / Mo / W，以及 2–3 层组合 |
| 厚度 | 0.5 / 1 / 2 / 3 / 5 nm |
| 终端 | 金属终端 / 碳终端（对碳化物） |
| 取向 | Cu(111)/中间层(111)/金刚石(111) 等 |
| 梯度 | 无 / 线性 / 阶跃 |
